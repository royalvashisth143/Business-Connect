# Business Connect — B2B / B2C Business Portal

A React + Vite business marketplace foundation with B2B/B2C marketplace, business directory, RFQ/quotation workflows, product management, dashboards, catalog/QR foundations, search analytics and Firebase-ready architecture.

## Roles
Super Admin, Admin, Buyer, Seller, Manufacturer, Wholesaler, Supplier, Retailer, Business Owner/Directory, Support Staff.

## UI theme
Dark Green + Light Green + White.

## Netlify
`netlify.toml` contains the Vite build command and SPA fallback redirect.

## Database
Firebase blueprint and Firestore rules are included. Production credentials are not embedded.
